# Personal Portfolio Website

Website portfolio pribadi yang dibuat menggunakan HTML, CSS, dan JavaScript murni tanpa framework.

## Fitur
- Responsive design
- Smooth scrolling navigation
- Modern UI design
- Section: Home, About, Projects, Contact

## Cara Menjalankan
Buka file `index.html` di browser Anda.

## Teknologi
- HTML5
- CSS3
- JavaScript (Vanilla)
